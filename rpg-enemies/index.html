Getting started

  1. Import the package. The Utility AI core comes with it. On the first load, RPG Enemies: Package Dependencies offers to install the AI Navigation package (required) and Post Processing (optional, demo only). On URP it then offers to convert the pack's materials. The art ships for the Built-in pipeline; HDRP is not supported.
  2. Press Play in Demo/Scenes/RPGEnemiesDemo.unity. Walk into the camp or press 1-7 to jump to a zone. F1 opens the AI debug view.
  3. Your own scene: bake a NavMesh, drag prefabs from Prefabs/Enemies onto it, and add Simple Combat Target and a Health to your player. The Manual's Quick Start chapter takes it from there.

Requirements: Unity 6 (6000.0 or newer), Built-in Render Pipeline (URP after conversion), AI Navigation package, legacy Input Manager for the demo player.

Try it first: the browser demo is the pack's demo scene as a WebGL build: the camp, all seven zones, the test player and the F1 AI Debug View.
